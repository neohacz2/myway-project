# Topic Digest Dashboard — Spec

## 개요

Topic Digest 파이프라인(YouTube 채널 자동 폴링 + NotebookLM artifact batch)의 상태를 한 화면에서 확인하고, 폴링·배치를 수동으로 즉시 실행할 수 있는 로컬 웹 대시보드.

## 범위

### 포함
- 파이프라인 상태 요약 카드: 마지막 폴링 시각, 마지막 배치 시각, 총 적재 영상 수, 다음 배치까지 남은 소스 수
- 최근 적재 영상 목록: 최대 10개, video ID + YouTube 링크
- 수동 트리거 버튼: "지금 폴링", "지금 배치" — 실행 결과(성공/실패 메시지) 화면에 표시
- NotebookLM 노트북 바로가기 링크
- 수동 새로고침(페이지 리로드 또는 새로고침 버튼)

### 제외
- **인증/로그인** — 로컬 개인 용도, 접근 제어 불필요
- **실시간 자동 갱신(polling/WebSocket)** — 수동 새로고침으로 충분, 복잡도 대비 가치 낮음
- **영상 제목 조회(YouTube API)** — ID + 링크만으로 시작. 다음 라운드에서 확장 가능
- **로그 뷰어** — 로컬 파일 브라우저로 충분. 화면이 복잡해짐
- **모바일 최적화** — 데스크톱 우선, 모바일 레이아웃은 이번 범위 밖

## 시나리오

### 1. 대시보드 진입 — 파이프라인 상태 확인

- **Given** — 파이프라인이 최소 1회 이상 실행된 적 있다 (state.json에 데이터 존재)
- **When** — 사용자가 대시보드 페이지(`/`)를 연다
- **Then** — 마지막 폴링 시각, 마지막 배치 시각, 총 적재 영상 수, 다음 배치까지 남은 소스 수가 화면에 표시된다

성공 기준:
- [ ] 마지막 폴링 시각이 "2026-05-28 09:00" 형태(KST)로 표시된다
- [ ] 마지막 배치 시각이 동일 형태로 표시된다
- [ ] 총 적재 영상 수가 state.json의 `ingested_video_ids` 길이와 일치하는 숫자로 표시된다
- [ ] `sources_added_since_last_batch` 값이 "다음 배치까지 N개" 형태로 표시된다

### 2. 대시보드 진입 — 파이프라인 미실행 상태

- **Given** — 파이프라인이 한 번도 실행되지 않았다 (state.json 없음)
- **When** — 사용자가 대시보드 페이지를 연다
- **Then** — 각 항목이 "아직 없음" 또는 "—" 으로 표시되며, 오류 없이 페이지가 로드된다

성공 기준:
- [ ] 페이지가 빈 화면이나 에러 없이 렌더된다
- [ ] 마지막 폴링·배치 항목에 "—" 또는 "아직 없음"이 표시된다

### 3. 최근 적재 영상 목록 조회

- **Given** — state.json에 ingested_video_ids가 1개 이상 존재한다
- **When** — 사용자가 대시보드 페이지를 연다
- **Then** — 최근 적재 순서로 최대 10개의 video ID와 YouTube 링크가 목록에 표시된다

성공 기준:
- [ ] 목록 항목 각각이 클릭 시 `https://www.youtube.com/watch?v={id}` 로 이동하는 링크다
- [ ] ingested_video_ids가 15개이면 가장 최근 10개만 표시된다
- [ ] ingested_video_ids가 0개이면 "아직 적재된 영상이 없습니다" 메시지가 표시된다

### 4. 수동 폴링 트리거

- **Given** — 대시보드가 열려 있다
- **When** — 사용자가 "지금 폴링" 버튼을 클릭한다
- **Then** — 버튼이 비활성화(로딩 상태)로 바뀌고, 실행이 완료되면 성공/실패 결과 메시지가 화면에 표시된다

성공 기준:
- [ ] 버튼 클릭 직후 버튼이 비활성화되고 로딩 표시가 나타난다
- [ ] 실행 성공 시 "폴링 완료" 텍스트(또는 동등한 성공 메시지)가 화면에 나타난다
- [ ] 실행 실패(예: Python 환경 없음) 시 "폴링 실패" 텍스트(또는 동등한 오류 메시지)가 화면에 나타난다
- [ ] 실행 완료 후 상태 카드의 수치가 최신 state.json 값으로 갱신된다

### 5. 수동 배치 트리거

- **Given** — 대시보드가 열려 있다
- **When** — 사용자가 "지금 배치" 버튼을 클릭한다
- **Then** — 버튼이 비활성화(로딩 상태)로 바뀌고, 실행 완료 후 성공/실패 결과 메시지가 표시된다

성공 기준:
- [ ] 버튼 클릭 직후 버튼이 비활성화되고 로딩 표시가 나타난다
- [ ] 실행 성공 시 "배치 완료" 텍스트(또는 동등한 성공 메시지)가 화면에 나타난다
- [ ] 실행 실패 시 "배치 실패" 텍스트(또는 동등한 오류 메시지)가 화면에 나타난다

### 6. NotebookLM 바로가기

- **Given** — 대시보드가 열려 있다
- **When** — 사용자가 "NotebookLM 열기" 링크(또는 버튼)를 클릭한다
- **Then** — `https://notebooklm.google.com/` 이 새 탭에서 열린다

성공 기준:
- [ ] 링크가 새 탭(`target="_blank"`)으로 NotebookLM을 연다

### 7. 새로고침

- **Given** — 폴링 또는 배치 실행 후 상태가 변경됐다
- **When** — 사용자가 새로고침 버튼을 클릭하거나 페이지를 리로드한다
- **Then** — 화면의 모든 수치가 현재 state.json의 최신 값으로 갱신된다

성공 기준:
- [ ] 새로고침 후 총 적재 영상 수가 실제 state.json의 `ingested_video_ids` 길이와 일치한다

## 불변 규칙

- **트리거 중복 방지**: "지금 폴링" 또는 "지금 배치" 실행 중에는 동일 버튼이 비활성화되어 중복 실행이 불가능하다
- **상태 데이터 최신성**: 페이지 로드 시점에 읽은 state.json 데이터를 표시한다 — 자동 갱신 없음

## 의존성

- Topic Digest 파이프라인(`scripts/topic-digest/`) 설치 및 `.env` 설정 완료
- `uv` 실행 가능한 환경 (Next.js 서버가 Python 스크립트 호출)
- `state.json` 경로: `scripts/topic-digest/state.json` (기본값 기준)
